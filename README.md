# LangChoice AI

LangChoice AI is an AI-powered English Proficiency Assessment and Language Test Recommendation System developed using Machine Learning and Streamlit.

## Features
- 12-question English proficiency assessment
- Grammar, Vocabulary, and Reading evaluation
- Random Forest prediction model
- AI-generated personalized performance report
- IELTS, PTE, and TOEFL recommendation
- Interactive and user-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
- Groq API

## Project Files
- app.py
- rf_model.pkl
- label_encoder.pkl
